# 0001. Київ і YASNO як джерело графіків для MVP

- **Статус:** прийнято
- **Дата:** 17.10.2026
- **Хто вирішив:** учень (рішення «робимо / не робимо»), ментор перевірив
- **Дослідження:** [2026-10-17 Джерела даних про відключення світла](../research/2026-10-17-ua-power-outage-data-sources.md)

## Контекст

На MVP є чотири тижні й одна людина на коді, тож стартуємо з одного міста. Розглядали Київ і Одесу.
Бот працює лише на сервері, без браузера, тому джерело має віддавати дані звичайним HTTP-запитом.

## Рішення

Місто — **Київ**. Графіки беремо з неофіційного JSON **YASNO**:
`GET https://app.yasno.ua/api/blackout-service/public/shutdowns/regions/25/dsos/902/planned-outages`.

- 60 черг (`1.1`…`60.1`), графік на сьогодні й завтра, слоти в хвилинах від півночі (0–1440),
  поле `updatedOn`.
- Опитуємо раз на 5 хв, зберігаємо останній отриманий графік.

## Чому не інші варіанти

- **Одеса (dtek-oem.com.ua):** лише HTML-сторінка, яку треба парсити, а `robots.txt` забороняє
  ботів (`Disallow: /`). Парсер зламається від будь-якої зміни верстки.
- **Сайт ДТЕК Київ (dtek-kem.com.ua):** закритий антиботом Incapsula, даних без браузера не отримати.
- **Офіційне API:** немає ні в YASNO, ні в ДТЕК, ні в Укренерго.

## Наслідки

- API не задокументоване й може змінитися будь-коли, ліцензії на дані немає. Тому джерело ховаємо
  за інтерфейсом `OutageSource`: валідація схеми, кеш останнього графіка, «станом на …» у кожному
  повідомленні, сповіщення розробнику, коли формат змінився або YASNO недоступне.
- Бажано отримати письмовий дозвіл YASNO до здачі гранту.
- Не перевірено: чи пускає YASNO запити з IP орендованого сервера. Перевірити до деплою.
- Інші міста — поза межами гранту.
